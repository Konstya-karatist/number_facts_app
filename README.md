# Факты о числах

Учебное Flutter-приложение для зачета. Пользователь вводит число, нажимает кнопку
`Получить факт`, а приложение загружает краткий факт о числе.

В корне проекта был изучен reference-архив `flutter_number_facts-main.zip`.
В нем запрос факта сделан через endpoint:

```text
https://api.isevenapi.xyz/api/iseven/{number}
```

Этот API возвращает JSON с полем `iseven`. В reference-проекте также был
вспомогательный запрос к Google Translate, но текущему приложению перевод не
нужен: интерфейс уже русский, а текст факта формируется в своем сервисе.

Ранее в проекте использовался `https://api.math.tools/numbers/fact?number={number}`,
но сейчас этот endpoint отвечает `401 Unauthorized`. Поэтому сервис заменен на
проверку `isevenapi` и собственную генерацию текста про четность числа. Если API
временно недоступен или не принимает число, приложение использует локальный
fallback и все равно показывает корректный факт.

## Функционал

- ввод числа;
- проверка пустого поля;
- запрос к API проверки четности числа;
- локальный fallback для отрицательных чисел и сетевых ошибок;
- индикатор загрузки;
- обработка сетевых ошибок;
- вывод результата в `Card`.

## MVC-архитектура

- `models/number_fact.dart` - модель данных одного факта о числе;
- `services/api_service.dart` - HTTP-запрос к isEven API и локальный fallback;
- `controllers/number_controller.dart` - проверка ввода и связь между view и service;
- `views/home_page.dart` - экран приложения и пользовательский интерфейс;
- `main.dart` - точка входа и настройка Material Design.

В проекте не используются Provider, BLoC, Riverpod, GetX или Clean Architecture.
Состояние экрана хранится прямо во `State` виджета через `setState`, чтобы код
оставался максимально простым для учебного проекта.

## Запуск

Установите зависимости:

```bash
flutter pub get
```

Запустите приложение в Chrome:

```bash
flutter run -d chrome
```

Проверьте проект анализатором:

```bash
dart analyze
```
